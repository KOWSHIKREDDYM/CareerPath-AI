# CareerPath AI 🚀

### An Agentic AI-Powered Career Guidance and Skill-Gap Analysis Platform for Engineering Students

CareerPath AI helps engineering students identify suitable career paths, analyze skill gaps, and build personalized learning roadmaps to prepare for their target careers.

🌐 **Live Demo:** https://careerpath-ai-ucxk.onrender.com  
📂 **GitHub Repository:** https://github.com/KOWSHIKREDDYM/CareerPath-AI

## ✨ Features

- **AI-Powered Career Guidance** — Explore career options based on your skills and goals.
- **Resume Analyzer** — Upload a resume and analyze its content.
- **Skill-Gap Analysis** — Identify skills to develop for your target career.
- **Personalized Learning Roadmap** — Get a structured learning path.
- **Learning Resources** — Discover resources to improve technical skills.
- **Project Recommendations** — Find projects aligned with your career goals.
- **Job Description Analyzer** — Compare your skills with job requirements.
- **Resume Improvement Suggestions** — Identify areas where your resume can improve.
- **AI Career Coach** — Get career-related guidance.
- **Interview Preparation** — Practice interview questions and evaluate responses.
- **Progress Tracking and Dashboard** — Monitor career readiness and learning progress.
- **User Authentication and Profiles** — Register, log in, and save career profile information.

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/KOWSHIKREDDYM/CareerPath-AI.git
cd CareerPath-AI
```

### 2. Create and activate a virtual environment

Windows PowerShell:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the application

```bash
uvicorn backend.main:app --reload
```

Open the application at:

http://127.0.0.1:8000

API documentation is available at:

http://127.0.0.1:8000/docs

## 🧠 How It Works

1. Create an account and complete your career profile.
2. Upload your resume for analysis.
3. Select your target career.
4. Review recommended careers, skill gaps, and learning resources.
5. Follow the roadmap, explore project recommendations, and track your progress.

## 🎯 Project Objective

The objective of CareerPath AI is to make career planning more structured and accessible for engineering students by combining resume analysis, career recommendations, skill-gap identification, and personalized learning guidance in one platform.
